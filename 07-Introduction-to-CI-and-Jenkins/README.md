# Exercise 7: Introduction to Continuous Integration (CI) and Jenkins

## Objective

Understand the fundamentals of Continuous Integration (CI) and install Jenkins locally using Docker.

## Topics Covered

- Introduction to Continuous Integration
- Key features and benefits of CI
- CI workflow
- Overview of CI/CD tools
- Introduction to Jenkins
- Jenkins jobs, builds, pipelines, plugins, and nodes

## Jenkins Installation

Jenkins was started locally using Docker.

```powershell
docker start jenkins
```

Jenkins dashboard: http://localhost:8080
